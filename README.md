# Mimir MVP 1

Private Norse-Celtic AI operating system.

**One Intelligence. Multiple Domains. One User in Control.**

The archived repo `BabyBlaxk/Mimir-core-MVP1` cannot receive commits. This is the live MVP 1.

## Quick start

```bash
git clone https://github.com/BabyBlaxk/Mimir-MVP1.git
cd Mimir-MVP1
cp .env.example .env
# set SESSION_SECRET
npm install
npm start
```

Open http://localhost:8080 and create the Founder.

See DEPLOYMENT.md for a ~$10/month VPS.
See MVP1_STATUS.md for honest working / partial / future status.

Provider keys stay on the server. The Vault cannot move money. iPhone PWA voice works only while the app is open.
